# Productadvisor — Alle mogelijke keuze-combinaties

Dit document is de **complete enumeratie** van alle mogelijke antwoord-
combinaties die een klant kan invullen tijdens de HLTY Consultation
(stap 1 + stap 2). Doel: visueel zien wat de scope is voordat we de
curatie-strategie kiezen.

**Modifiers** (dieet stap 3, leefstijl stap 4) zijn **niet** als
aparte mappings opgenomen — die behandelen we als filters bovenop de
basis-mappings (anders krijgen we 16.848 combinaties wat onhaalbaar is).

## Strategie-opties

### Optie A — Volledige curatie (351 mappings)

**Aanpak**: jij + fysio bepalen per combinatie (1 t/m 351) een lijst van 5–8
kandidaat-producten met vooraf bedachte uitleg-teksten.

| | |
|---|---|
| Curatie-werk | 351 mappings × ~10 min/mapping = ~60 uur |
| Kwaliteit | Maximaal — elke combinatie bewust gekozen |
| 2-doelen kwaliteit | Optimaal — bewuste synergie |
| Onderhoud bij assortimentswijziging | Hoog — alle mappings moeten worden gereviewd |
| Wanneer kiezen | Als de Productadvisor jullie kerntool wordt en perfectie het verschil maakt |

### Optie B — Algoritmische combinatie (27 mappings + algoritme)

**Aanpak**: jullie cureren alleen de 27 enkele-doel mappings. Voor de 324
dubbele-doel cases combineert een algoritme automatisch de top-kandidaten
uit beide enkele-doel mappings.

| | |
|---|---|
| Curatie-werk | 27 mappings × ~10 min = ~5 uur (één fysio-sessie) |
| Kwaliteit | 85% — 1-doel cases perfect, 2-doel cases redelijk |
| 2-doelen kwaliteit | Wisselend — sommige paren werken goed (slaap+energie), andere minder logisch |
| Onderhoud | Laag — 27 lijstjes bijhouden |
| Wanneer kiezen | Snel naar live; later overschakelen naar optie C als nodig |

### Optie C — Hybride (27 + extra ~10 logische paren)

**Aanpak**: 27 enkele-doel mappings + handmatig cureren van de 10 meest
logische / meest voorkomende dubbele-doel paren. Andere paren via algoritme.

Welke 10 paren zijn waarschijnlijk logisch om uniek te cureren:

| # | Paar | Reden |
|---|------|-------|
| 1 | Slaap + Energie | Klassieke samenhang — slecht slapen veroorzaakt vermoeidheid |
| 2 | Slaap + Stress | Stress beïnvloedt slaap direct |
| 3 | Energie + Stress | Stress put uit |
| 4 | Energie + Focus | Mentale energie raakt elkaar |
| 5 | Stress + Focus | Stress vermindert focus |
| 6 | Spieren + Gewrichten | Sporters met klachten |
| 7 | Hart + Energie | Cardio-uitputting / vermoeidheid bij hartproblemen |
| 8 | Hormonen + Energie | Hormoonschommelingen → energie-issues |
| 9 | Hormonen + Slaap | Menopauze + slaapproblemen |
| 10 | Weerstand + Stress | Stress verlaagt immuunsysteem |

| | |
|---|---|
| Curatie-werk | 27 + 10 = 37 mappings × ~10 min = ~7 uur (twee fysio-sessies) |
| Kwaliteit | 95% — 1-doel perfect, top-10 2-doel paren perfect, overige redelijk |
| Onderhoud | Middel — 37 lijstjes bijhouden |
| Wanneer kiezen | Beste balans tussen kwaliteit en haalbaarheid |

## Mijn aanbeveling

**Optie C (hybride)** voor de eerste live-versie. Redenen:

1. **Haalbaar in 2 fysio-sessies** — niet doorslaan in 60 uur curatie
2. **95% kwaliteit** — de meest voorkomende dubbele-doel paren krijgen aandacht
3. **Schaalbaar** — als blijkt dat klanten vaak een specifiek niet-gecureerd paar kiezen, kan dat alsnog later uniek worden gecureerd
4. **Behoudt de architectuur**: regels eerst, AI alleen bij stap 5
